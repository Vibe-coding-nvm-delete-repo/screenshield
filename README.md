# ScreenShield — Minimalist Windows Privacy Shield for Any App or Website

A fast, minimalist `.NET 8` Windows 10/11 desktop app that lets you manage **all active desktop apps and browser websites** in 4 clean tabs (`All Apps & Sites` | `Allowed` | `Blocked` | `Settings`), protect blocked items when Upwork Time Tracker is running, and automatically hide the Windows taskbar (`SHAppBarMessage` `ABS_AUTOHIDE`) so blocked app icons never leak into screenshots.

---

## How It Works

1. **4-Tab Minimalist Workflow**
   - **`All Apps & Sites`**: Automatically lists every currently open desktop application (via native Win32 `CreateToolhelp32Snapshot` + `EnumWindows`) and every open browser tab/site (Chrome, Edge, Brave, Firefox, Opera, Vivaldi, Arc).
   - **`Allowed`**: Any app or site **not** in `Blocked` is automatically `Allowed`.
   - **`Blocked`**: Check 1 or many rows to **Block Selected** (bulk add) or **Allow Selected** (bulk remove), double-click any row to toggle in `< 1 ms`, or type any custom domain (`whatsapp.com`, `discord.com`, etc.) into **`+ Block Site`**.
   - **`Settings`**: Inline settings sheet (zero modal popups) with Light & Dark system theme sync and Windows 11 rounded DWM chrome.
2. **Windows Taskbar Auto-Hide Shield**
   - Whenever a blocked app or site is open while protection is active, ScreenShield calls Windows' official `SHAppBarMessage(ABM_SETSTATE, ABS_AUTOHIDE)` so the bottom taskbar slides out of sight (preventing blocked app icons on the taskbar from appearing in screenshots).
   - On close/exit or when no blocked items are open, ScreenShield **always restores** your original Windows taskbar setting.
3. **Zero-Injection Screenshot Exclusion for ScreenShield Itself**
   - ScreenShield sets `SetWindowDisplayAffinity(Handle, WDA_EXCLUDEFROMCAPTURE)` (`0x11`) on its own window so Upwork screenshots never even see ScreenShield.

## Build, Test, and Action Latency Table

```powershell
# Build Release executable (ScreenShield.exe)
dotnet build -c Release

# Run full test suite (WCAG contrast, hit sizes, TaskbarShield, Catalog, ActionCoverage + timings)
dotnet test

# Run standalone CLI screenshot self-test:
#   exit 0 = proven excluded on unlocked desktop
#   exit 2 = affinity readback verified (0x11), desktop capture unavailable
#   exit 1 = failed
dotnet run --project src/DiscordShield/DiscordShield.csproj -- --self-test
```
